# 小窗浏览器 v1.4.0 发布验证报告

本文记录 v1.4.0 正式发布前完成的自动验证和人工验收项目。运行发布包前请先退出旧版小窗，再从完整解压后的目录启动 `XiaoChuang.exe`。

## 已完成的自动验证

- Release x64 与 x86 均使用 C++20、`/W4` 构建，新代码零编译警告。
- MSVC 代码分析已运行；已修复检测到的 COM 返回值问题。
- x64 与 x86 的 65 项核心测试全部通过：旧配置及旧预设迁移、多标签预设往返、预设重名检查、启动焦点保护、配置范围校验、窗口状态转换、最大化拖动开关与恢复、视频比例计算、短按/400ms 长按、Raw Input 中键/双侧键解析、严格的输入控件识别、活动视频选择和站点适配。
- x64 实际启动后成功创建主窗口与 WebView2，并通过 `WM_CLOSE` 正常退出，退出码为 0。
- 图标包含 16/20/24/32/40/48/64/128/256px，已统一嵌入 EXE、窗口、任务栏/Alt-Tab 和托盘。
- 已做窗口级回归：托盘单击恢复、地址栏持有输入焦点时 `9` 隐藏/显示、二次启动拉起原窗口、透明度控件条件显示、固定透明挖孔、快速 `0/9` 防抖、无缝最大化空白区命中与非客户区关闭均通过。
- 已用 12 个标签验证标签宽度会自动收窄，系统滚动箭头保持隐藏，最右侧仍保留窗口拖动区。
- 已使用本地 WebView2 页面测试网页全屏：主窗口尺寸不变且顶部栏保持可见；开启比例自动适配后，16:9 测试由 1000×700 临时调整为 1000×665，Esc 后恢复 1000×700。
- 已模拟系统输入焦点切换，设置窗口在事件前后均保持于主窗口上方，未再出现主窗口顶部条遮挡。
- 已做真实窗口输入回归：鼠标侧键 1、侧键 2 均可绑定为“隐藏/显示”，配置会立即落盘，随后可分别隐藏和恢复窗口；沉浸进入后具备分层/穿透样式，退出后恢复标准窗口样式。
- 已用在线 Bilibili 主页验证同地址新标签和关闭最后一个标签后均保存真实网页标题，不再写入“主页”或“新标签页”。
- 已验证小窗未获得前台焦点且未经点击时仍立即注册 `0`，经过输入保护定时检查后仍有效；启动后新的外部输入焦点仍会正常触发保护。
- 圆形挖孔已恢复为固定完全透明，孔外与整窗 Alpha 保持不透明；透明度控件只在“整体透明”风格下显示。
- 已检查 ATK HUB 与《洛克王国：世界》WeGameLauncher 的嵌入清单，两者均为 `requireAdministrator`；输入保护现在会跳过跨权限 UI Automation 误判，并保留 Windows 注册的键盘热键。
- 正式 EXE 清单为 `requireAdministrator`，启动时会出现 Windows UAC；窗口自动化使用单独的 `SmokeTestAsInvoker` 构建开关，不影响交付包权限。
- 已做即时主题回归：切为深色后主窗口标题栏属性立即变更，按钮填充为 `RGB(37,41,55)`；切回浅色后立即恢复白色，无需重新打开设置。
- 已做地址栏消息回归：双击测试网址后选择范围为 `0–25`，完整覆盖 25 个字符。

## 人工验收项目

1. 在 100% / 150% / 200% DPI 下检查标签栏、地址栏、设置滚动、书签和预设窗口。
2. 点击无缝最大化，确认精确覆盖当前显示器工作区、四周无留白且切到外部软件后不出现蓝色顶边；默认顶部空白不响应拖动，开启设置项后才允许从顶部拖动恢复。
3. 在 Bilibili、抖音、YouTube 分别测试播放/暂停、点按 ±5 秒、长按快进/倒退、上一集/下一集和网页内全屏。网页内全屏应只覆盖小窗网页区域，非沉浸模式保留顶部栏；在网页全屏状态按 `0` 进入和退出沉浸，视频必须始终保持网页全屏；再分别关闭/开启“按画面比例调整小窗”比较黑边。
4. 在地址栏、网页搜索框和游戏聊天框输入，确认字符不会触发任何小窗全局热键。
5. 测试固定完全透明的圆形挖孔，以及整体透明风格的 0/50/100% 不透明度；后者的控件只应在对应风格下出现。再测试预设、多标签和快速反复按 `0` / `9`。
6. 开启“隐藏时允许媒体热键”，确认隐藏后五项媒体控制有效、沉浸热键无效；关闭后应仅保留显示/隐藏。
7. 在《原神》等无边框全屏下检查置顶。真正绕过 DWM 的独占全屏无法由普通桌面窗口覆盖，这是系统限制。
8. 对鼠标锁定类游戏检查整体透明模式：系统光标被隐藏/锁定时视频应保持可见；显示自由光标并移入时应在约 80ms 后隐藏。
9. 托盘模式下验证左键单击打开、右键菜单的打开/退出；隐藏前鼠标即使聚焦在地址栏或网页输入框，再按 `9` 也应立即显示。
10. 切换或关闭标签时旧网页应立即消失；标签栏右键验证“关闭其他标签页”和“关闭全部标签页”。
11. 首次和后续启动均确认出现 UAC 提示；进入 ATK HUB、WeGameLauncher 和游戏窗口内部，再测试键盘 `0`、`9`、媒体键和鼠标侧键，它们不应因点击自绘画布而整体失效。
12. 在设置中反复切换深色、浅色和跟随系统，主窗口标签、地址栏及所有按钮必须一次同步变色；双击地址栏应选中完整网址。

## GPU / HAGS 掉帧对照

在设置中点击“复制诊断信息”，记录 WebView2 Runtime、HAGS、渲染模式、活动视频尺寸和丢帧计数。建议用同一视频、同一画质分别测试：

| HAGS | 渲染模式 | 游戏状态 | 记录 |
|---|---|---|---|
| 开 | 自动 GPU | 前台全屏 | 待测 |
| 关 | 自动 GPU | 前台全屏 | 待测 |
| 开 | 软件兼容 | 前台全屏 | 待测 |
| 关 | 软件兼容 | 前台全屏 | 待测 |

软件兼容模式需要重启。默认应保持“自动 GPU”；`--disable-gpu` 仅用于故障对照。

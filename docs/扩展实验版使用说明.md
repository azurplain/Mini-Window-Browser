# 小窗浏览器 v1.4.6 扩展实验版 · 使用说明

**这是独立长期实验版本，不是正式版。** 它用于验证 Microsoft Edge WebView2 的 Chromium 扩展兼容性，不保证所有 Chrome/Edge 扩展可用。与正式 v1.4.5 分开安装和测试，不影响正式版的下载入口。

## 第一次使用

1. 从 GitHub Releases 找到标记 **Pre-release** 的 `v1.4.6-extensions-lab` ZIP，完整解压到一个**独立的新文件夹**，不要覆盖正式版。
2. 直接双击 `XiaoChuang-ExtensionsLab.exe`，**不需要管理员权限**。它会在程序内的 `extensions-lab-data/` 目录保存自己的配置、WebView2 数据、扩展源文件与日志；不读取正式版的 `config.ini` 和 Cookie。
3. 在网址栏右侧点击 **🧩 拼图图标**，打开原生扩展管理窗口。
4. 点击 **安装本地扩展**，选择已解压的浏览器扩展文件夹；目录内必须有 `manifest.json`，当前只尝试 Manifest V3（`"manifest_version": 3`）。
5. 安装后列表显示扩展名称和状态。勾选行首开关可启用/停用扩展；单击右侧“删除”或底部删除按钮可卸载扩展。下方“刷新列表”可重新读取 WebView2 Profile 状态。

注意：没有 Chrome Web Store 一键安装功能。不支持直接选择 CRX/ZIP 文件安装；需要合法来源提供的解压扩展文件夹。

## 浏览器卡住时怎样管理扩展？

**不需要安全模式。** 在实验版主文件夹双击 **`扩展管理.cmd`**，会启动独立的 Windows 原生扩展管理窗口，而不是进入可能白屏的网页。

管理窗口使用同一实验版 WebView2 Profile，因此对扩展的启用、停用和删除会反映到实验版。必要时退出主浏览器再操作；操作后重新打开小窗核查。外部管理器虽然不依赖主浏览器窗口的消息循环，但仍需要 WebView2 Runtime 与 Profile 正常初始化。若底层运行时/数据损坏，它也可能无法完成操作，界面应明确提示失败。

## 安全与隐私

- **实验版使用普通用户权限**。如果从管理员终端启动，可能被拒绝；建议通过资源管理器正常双击。
- 扩展有能力读取或修改其获授权的网站内容。只安装来源可信、确有必要的扩展，先了解它声明的权限。复杂扩展可能导致视频性能降低、网页空白或与快捷键发生冲突。
- 导入扩展时，小窗复制一份到实验版自管文件夹，避免原始目录被移动后安装失效。文件超过 50 MiB、条目超过 1000、包含符号链接或缺少 MV3 清单时会被拒绝。
- 小窗的日志会记录安装、启停、卸载和 WebView2 状态，但默认不记录网页 URL、标题、搜索词、Cookie 或输入内容。日志不会自动上传。
- 切换场景预设**不会**启用、禁用或卸载扩展。

## 重要限制

- WebView2 没有完整的 Chrome 扩展工具栏，一些依赖扩展弹出页、徽章、页面行为或特殊 `chrome.*` API 的扩展可能没有功能。
- 小窗的多个标签仍共享一个 WebView2 网页视图；切换标签不是同时运行多个独立后台标签。
- 当前主要支持“解压目录安装、列表、启停、卸载”的基础管理。图形化权限详情、复杂的扩展动作弹窗、版本自动更新、扩展商店还未实现。
- **Windows CI 主要测试能否编译和运行核心逻辑，不能取代实际扩展安装、网页渲染和 GPU 白屏测试**。实验版建议先用不含敏感权限的简单 MV3 扩展验证，再逐步测试常用扩展。
